Debug bar
====================
The debug bar is a secondary mode for MES that can be enabled via the :ref:`Settings dialog`.

This adds a navbar under the default Mbin navbar that lets you block/unblock specific mods from firing.

More generally, the debug bar provides a way of manipulating mods more rapidly without needing to open the MES modal each time.

When a specific mod is selected in the dropdown, opening the main MES modal will open that mod's settings page.

Filters
^^^^^^^^^^
Block filters are applied on top of your existing MES preferences, so you can keep the habitual toggle ON/OFF state of
mods you personally use intact while applying a secondary level of block/unblock filters over them for testing purposes.

Mods explicitly blocked in the debug bar will be skipped entirely, and mods explicitly allowed will be applied, regardless
of the normal MES settings.

This allows for quickly troubleshooting interactions between mods. You can also bulk disable or enable mods. Used in conjunction
with atomic block/unblock filters, you can quickly test how specific mods interact without having to manually toggle them all.

To change the internal settings of mods while the debug bar is enabled, open the main MES menu to expose their granular settings.

.. note::
   Toggle buttons inside the MES modal are disabled while the debug bar is active.
   
.. caution::
   Mod settings changed in the MES modal are shared between normal and debug mode.

Notifications panel
^^^^^^^^^^^^^^^^^^^^^
Finally, the debug bar provides a simplified panel which exclusively contains :ref:`log events <Log levels>` generated by :js:func:`log`.
Messages, warnings, and errors emitted by MES and mods will be pushed into this tray,
which can be opened via the caret icon :fa:`fa-solid fa-caret-down` at the far right.


Version information
^^^^^^^^^^^^^^^^^^^^^
The MES version label doubles as a link to the `GitHub issue tracker <https://github.com/aclist/kbin-kes/issues/new/choose>`_.
Clicking the version label will open a new issue and pre-populate the form fields with the current version number.
